# CodeBook - Human Activity Recognition Summary Dataset

## Dataset Overview
Summarizes mean and standard deviation motion sensor variables from the UCI HAR Dataset, grouped by subject and activity.

## Identifiers
- `subject`: ID of the experiment participant (1–30).
- `activity`: Name of activity performed (6 levels: WALKING, WALKING_UPSTAIRS, WALKING_DOWNSTAIRS, SITTING, STANDING, LAYING).

## Units & Normalization
All measurement variables are bounded within [-1, 1] and unitless due to feature normalization in raw data preprocessing.

## Data Processing Steps
1. Combined training and test datasets.
2. Extracted measurements containing mean() and std().
3. Applied descriptive activity names.
4. Cleaned variable names into snake_case format.
5. Aggregated data by subject and activity using mean().
